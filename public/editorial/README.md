# Editorial photography

Three named slots, all optional:

```
hero.jpg            → replaces the illustrated home page hero (landscape 16:9, 2400px+)
our-story.jpg       → replaces the home page story image (portrait or square)
sustainability.jpg  → the right half of the home page sustainability band
                      (portrait or square; it is cropped to a tall half-width panel)
```

`.jpg` `.jpeg` `.png` `.webp` `.avif` all work. Remove the file to fall back to
the generated artwork.
